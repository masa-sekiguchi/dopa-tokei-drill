## この版で追加したもの：とけいのスキル（9つ）

アナログ時計の絵を出して、「◯時◯分」を1桁ずつ入力して答えます。「9時の20分前は？」のような、時計の読み方を段階的に練習できます。

| ID | 名前 | 内容 |
| --- | --- | --- |
| `g1-clock-hour` | とけい ○じ | ちょうどの時刻を読む |
| `g1-clock-half` | とけい ○じはん | ○時30分を読む |
| `g2-clock-5` | とけい 5分ずつ | 5分刻みで読む（分の数字つき） |
| `g2-clock-1` | とけい 1分ずつ | 1分刻みで読む |
| `g2-clock-next` | あと何分で ○時 | 次の時刻まで、あと何分か（60 − 分） |
| `g2-clock-shift-pic` | ○分前・○分後（ず） | 「9時の20分前」。時計に戻る分を色で示す |
| `g3-clock-shift` | ○時の ○分前・後 | 絵なしで「9時の20分前」を答える |
| `g3-clock-shift2` | ○時○分の ○分前・後 | 「8時50分の20分後」。時をまたぐ |
| `g3-clock-elapsed` | じかんの ながさ | 「8時40分から9時15分まで」何分か |

タイトルの「とけいの れんしゅう」ボタンで、まだマスターしていない最初のとけいスキルを練習できます。3回続けて間違えると、ヒントと時計の強調が出ます。短い針は分に合わせて動くので、「8時40分」では8と9のあいだを指します。

### こたえかたを選べる（すうじ／はり）

タイトルの「とけいの れんしゅう」の下と、せっていで「すうじ」（数字ボタン）と「はり」（時計の針を動かす）を切りかえられます。選んだ方法は端末に保存されます。

- 「はり」で答えるのは、答えが時刻の問題（とけいの読み・○分前○分後の6スキル、`g1-clock-hour` 〜 `g3-clock-shift2`）。時計の外がわをなぞると長い針（分）、内がわをなぞると短い針（時）が動き、「できた！」で答えあわせをします。読みの問題は、時刻が文字で出て、針をあわせます。
- 「あと何分」「じかんの ながさ」は答えが分なので、どちらの設定でも数字ボタンです。
- 針の位置は数字に直して、いつもの入力と同じ流れで採点します（まちがいの表示・ヒント・ドパキチの動きは共通）。仕組みは `app/js/problems.js` の `handsDigits`、針の操作は `app/js/main.js` の `wireHands`。

変更したファイル：`app/js/problems.js`（時計の描画と出題）、`app/js/skills.js`（スキル定義）、`app/js/main.js`（時計セルの描画とタイトルのボタン）、`app/style.css`、`app/index.html`、フォント（「後」「○」を追加して再生成）、`tests/app_clock.test.mjs`。

# ドパドリル

算数を1問解くたびに、演出と音楽がどんどん盛り上がっていく計算ドリルです。ブラウザだけで動きます。

マスコットの「ドパキチ」が入力した数字を運び、正解すると祝ってくれます。問題を進めるほど画面と音が増えていき、最後はお祭りのような状態になります。まちがえても勢いは落ちず、ゲームオーバーもありません。

## 特徴

- 小学1〜6年の計算58スキル（学習指導要領に基づく）。足し算・ひき算・かけ算・わり算、筆算の途中入力、小数、分数、割合など
- 「じぶんレベル」モード：実力チェックの結果から始め、習熟に合わせて次のスキルを解放します
- 学年別モード、練習、復習、スキルツリー画面
- 全問正解で100点。初回正解率が80%以上なら、制限時間付きのエクストラで100点を超える得点を狙えます
- 音楽と効果音はすべてWeb Audio APIで合成しています（音声ファイルは使っていません）
- スマートフォンの縦画面とPCに対応。PCでは数字キーとBackspaceで入力できます
- 設定で動きの強さを調整できます。ミュートもあります
- 記録はすべて端末内（localStorage）に保存し、外部には送信しません

## 遊び方（ローカル）

ビルドは不要です。`app/` を静的に配信するだけで動きます。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを使っているため、`file://` で直接開くと動きません。

## テスト

Node.js 20以上で実行します。

```bash
node --test tests/*.test.mjs
```
